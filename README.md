# Desktop-mate_Mobile
日本語 : これはDesktop Mateの非公式モバイル版です。ゼロから開発したため、機能は似ていますが、Desktop Mateに使われているテクスチャやその他の要素は一切使用していません。English : This is an unofficial mobile version of Desktop Mate. I built it from scratch, so while the functionality is similar, I haven't used any of the textures or other elements from Desktop Mate.
